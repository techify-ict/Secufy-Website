# Secufy Website - Image Upload Guide

## Where to Upload Your Images

All images should be placed in the **`images/`** folder in your project directory:

```
windsurf-project-8/
├── images/              ← Upload your images here
│   ├── logo.png
│   ├── hero-image.jpg
│   ├── secufy-og-image.jpg
│   └── about-image.jpg
├── index.html
├── styles.css
└── script.js
```

## Priority Images to Upload

### 1. **Logo** (HIGHEST PRIORITY)
- **Filename**: `logo.png` or `logo.svg`
- **Where it appears**: Navigation bar and footer
- **Recommended size**: 200x60px (or maintain aspect ratio)
- **Format**: PNG with transparent background or SVG
- **Current status**: Using Font Awesome shield icon

### 2. **Hero Image** (HIGH PRIORITY)
- **Filename**: `hero-image.jpg` or `hero-image.png`
- **Where it appears**: Right side of hero section
- **Recommended size**: 800x800px
- **Format**: JPG or PNG
- **Current status**: Using animated shield icon

### 3. **Social Media Image** (MEDIUM PRIORITY)
- **Filename**: `secufy-og-image.jpg`
- **Where it appears**: When sharing on Facebook, LinkedIn, Twitter
- **Recommended size**: 1200x630px
- **Format**: JPG
- **Current status**: Placeholder URL in meta tags

### 4. **About Section Image** (MEDIUM PRIORITY)
- **Filename**: `about-image.jpg`
- **Where it appears**: About section
- **Recommended size**: 600x600px
- **Format**: JPG
- **Current status**: Using gradient placeholder

## How to Upload

### Option 1: Drag and Drop (Easiest)
1. Open the `images/` folder in Windows Explorer
2. Drag your image files into the folder
3. Rename them to match the filenames above

### Option 2: Copy/Paste
1. Navigate to: `C:\Users\moh_b\CascadeProjects\windsurf-project-8\images\`

## Image Specifications

### Logo Requirements
- **Transparent background** (PNG or SVG)
- **High resolution** for retina displays
- **Horizontal orientation** works best
- **Colors**: Should work on both light and dark backgrounds

### Hero Image Requirements
- **Professional security-related photo** (security guard, surveillance, building, etc.)
- **High quality** (at least 800x800px)
- **Good lighting** and clear subject
- **Matches brand colors** (blue and yellow if possible)

### Social Media Image Requirements
- **Include company name** "Secufy"
- **Include tagline** or key message
- **Professional design** with brand colors
- **1200x630px** (Facebook/LinkedIn standard)
