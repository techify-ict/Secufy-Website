# Images Folder

Upload your Secufy branding assets and visuals here.

## Required Images:

### Logo Files
- **logo.png** or **logo.svg** - Main Secufy logo (recommended: transparent background)
  - Recommended size: 200x60px or similar aspect ratio
  - Used in: Navigation bar, footer

### Hero Section
- **hero-image.jpg** or **hero-image.png** - Main hero visual
  - Recommended size: 800x800px
  - Used in: Hero section right side (currently showing shield icon)

### Open Graph / Social Media
- **secufy-og-image.jpg** - Social media preview image
  - Recommended size: 1200x630px
  - Used when sharing website on Facebook, LinkedIn, Twitter

### Optional Images

#### Service Images (if you want to replace icons with photos)
- **camera-security.jpg** - Camera surveillance
- **object-security.jpg** - Security guards
- **alarm-center.jpg** - Alarm monitoring center
- **access-control.jpg** - Access control systems

#### About Section
- **about-image.jpg** - Company photo, team, or office
  - Recommended size: 600x600px
  - Used in: About section (currently showing gradient placeholder)

#### Sector Images (optional)
- **sector-retail.jpg**
- **sector-healthcare.jpg**
- **sector-education.jpg**
- etc.

## Image Optimization Tips

1. **Compress images** before uploading to improve page load speed
2. **Use WebP format** when possible for better compression
3. **Provide retina versions** (@2x) for high-DPI displays
4. **Use descriptive filenames** for SEO (e.g., secufy-beveiliging-rotterdam.jpg)
